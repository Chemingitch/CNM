CNM —— 本机模型 + 云端中转，合成一条 OpenAI 兼容服务

动手之前，30 秒扫一眼这一页：

【这个包装了什么】
  · CNM 程序本体（.NET 运行时是自带的，不用另外装）
  · llama.cpp 引擎（Vulkan 版，跑本机 GGUF 模型）
  · 界面文件
  一共约 250 MB，默认装在系统盘的 Program Files\CNM。

【模型不在这个包里】
  GGUF 模型都是几个 GB 起步，所以单独选地方放：
  下一步会让你挑模型目录（默认选空间最大的那个盘），
  装完之后在「设置 → 模型目录」里随时能改。

【运行需要什么】
  · Windows 10 / 11 64 位
  · 微软 WebView2 运行时（Win11 和较新的 Win10 自带；
    没检测到的话，安装程序会用它自带的引导器帮你装，需要联网）
  · 想跑本机模型：显卡驱动尽量新（CNM 走 Vulkan）

【装完怎么用】
  · 服务地址：http://127.0.0.1:1234/v1
  · 局域网里别的设备要用它：把 127.0.0.1 换成这台电脑的 IP
    （安装时默认已经帮你在防火墙里放行了 1234 端口）
  · API Key 在「设置」页里，能看、能改、能重新生成
  · 「模型库 → 在线浏览」直接挑模型下载；
    「服务与日志 → 守望者」接你买的中转站

【你的数据在哪】
  配置、上游地址、Key、用量统计都在 %APPDATA%\CNM。
  卸载时默认保留（卸载程序会问你要不要一起删）。
